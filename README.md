# Kakwak Apps

The public site for the Android apps by Kakwak: https://kakwak123.github.io/apps/

Pushing to `main` builds and deploys the site with GitHub Actions.

## Add an app

1. Add it to `src/data/apps.ts`.
2. Write `docs/<slug>.md`.
3. Add the slug to `sidebars.ts`, the navbar in `docusaurus.config.ts`, and the table in `docs/privacy.md`.

This repository is public. App code, internal reports, server addresses and personal details do not belong here.
